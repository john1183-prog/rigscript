`run.sh` compiles the pure engine and the JVM tests with a standalone kotlinc (fetched by `setup.sh`; no Gradle, no Android, kotlinx.serialization and JUnit are stubbed) and runs them in about a minute; it speeds up the loop but never replaces CI. To regenerate goldens after an intended engine change, copy `/tmp/localjvm-out/run/build/golden-actual/*.txt` to `app/src/test/resources/golden/`, justify it in `V2_DECISIONS.md` and let CI confirm. New pure engine files go into `main_files.txt`, new test files into `test_files.txt`.
